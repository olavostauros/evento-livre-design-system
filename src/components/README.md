# Components

- `primitives/`  smallest building blocks (Button, Input, Text, Icon)
- `patterns/`    compositions of primitives (Form, Card, Modal, DataTable)
- `b2b/`         producer-facing compositions (dashboards, tables, reports)
- `b2c/`         lead-facing compositions (event discovery, alerts, hand-off to the seller)

One folder per component. Shared primitives first; audience folders only for
things that genuinely differ.
