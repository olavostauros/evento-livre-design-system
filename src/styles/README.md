# Styles

Global CSS and the Tailwind entry file. Keep this minimal; tokens do the work.

- `index.css`   Tailwind entry: imports `tailwindcss`, `fonts.css`, `theme.css`
- `fonts.css`   `@font-face` for the self-hosted variable fonts
- `fonts/`      Geist, Geist Italic, Geist Mono, Bricolage Grotesque (woff2) and their OFL licences
- `theme.css`   generated by `scripts/build-theme.ts`. Do not edit by hand.

Apps set `data-theme="light|dark"` (optional, OS preference otherwise) and
`data-register="b2b|b2c"` (B2C is the default) on `<html>` or any subtree.
